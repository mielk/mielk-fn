# Changelog

All notable changes to this library are documented in this file. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the library uses [Semantic Versioning](https://semver.org/).
Entries are written by hand; `npm version` moves them from Unreleased to the released version.
Versions up to 1.2.6 were generated by standard-version and are kept unchanged.

## [Unreleased]

### Added

- `invert` takes `ignoreDuplicatedKey`: `true` keeps the first key of a repeated value (TASK-188).
- `getCapturedNumber` accepts a `RegExp` as well as a pattern string (TASK-188).
- Exported type `Primitive` (including `bigint` and `symbol`), used by `isPrimitive` (TASK-188).
- `RedisConfig.onError` receives error events of the Redis client (TASK-188).
- TSDoc comments for every export (TASK-188).

### Changed

- **Breaking:** the main entry point exports every function and type by name; the namespaces `dates`, `numbers`, `objects`, `strings`, `types` and `variables` are removed. Migration: import functions by name, e.g. `numbers.formatPercent` becomes `formatPercent` (TASK-188).
- **Breaking:** the Redis module is available only from `mielk-fn/redis`, and `redis` is an optional peer dependency (`^5`). Migration: import from `mielk-fn/redis` and install `redis` in the application that uses it (TASK-188).
- **Breaking:** `strings.clear` is renamed to `collapseWhitespace`. Migration: replace imports of `clear` (TASK-188).
- **Breaking:** `invert` throws an error when two keys have the same value; before, the last key silently won. Migration: pass `ignoreDuplicatedKey: true` to keep the first key instead (TASK-188).
- **Breaking:** `merge` without `override` keeps the first value of a key also when it is `0`, `''`, `false` or `null`; before, such a value was replaced by the next one. Its signature is `merge(objects: readonly unknown[], override?): Record<string, unknown>`. Migration: pass `override: true` where the later value should win (TASK-188).
- **Breaking:** `invert` declares the values of its result as strings (`` `${T}` ``), as returned at run time; before, numeric keys were declared as numbers. Migration: convert the values with `Number()` where a number is needed (TASK-188).
- **Breaking:** `toMap` returns a typed `Map<K, T>` (or `Map<K, V>` with a value callback) instead of `Map<any, any>`, and `isPrimitive` narrows to `Primitive`. Migration: remove casts that relied on `any` (TASK-188).
- **Breaking:** `RedisConfig` is a type with `port` as a number, and `getRedisClient` throws when a later call passes a configuration different from the existing client. Migration: pass the port as a number and configure the client once (TASK-188).
- `getRedisClient` connects parallel callers through one connection attempt and reconnects a client that was closed (TASK-188).
- `addRedisKey` serialises the content before it connects, so content that `JSON.stringify` rejects (`TypeError`) fails without a connection to Redis (TASK-188).
- The Redis module no longer writes the server address and connection errors to the console; use `onError` (TASK-188).
- **Breaking:** Node.js 24 or later is required (`engines.node`); before, no Node.js version was declared. Migration: update Node.js to version 24 or later in the applications and build environments that use the library (TASK-188).
- License changed from ISC to MIT (TASK-188).

### Removed

- **Breaking:** the type `ObjectAny`. Migration: use `Record<string, unknown>` (TASK-188).

### Fixed

- `getRedisClient` sends the configured password to the server (TASK-188).
- `formatWithSign` and `formatPercent` return zero without a sign for values that round to zero, e.g. `'0'` instead of `'-0'` (TASK-188).
- `getCapturedNumber` returns `undefined` instead of `NaN` when the captured group is not a number (TASK-188).
- `invert`, `modifyKeys` and `merge` write a `__proto__` key as an own property instead of changing the prototype of the result (TASK-188).
- `modifyKeys` names `null` correctly in its error message (TASK-188).
- The package no longer contains compiled tests and an empty helper module (TASK-188).
